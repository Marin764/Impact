# 首尔 Citywalk 夜景旅行地图

一个为手机使用优化的可编辑旅行 Web 工具。当前已经把 `首尔4天3晚_Citywalk夜景加强版.html` 中的核心路线整理为 4 天地图行程。

## 已包含

- 按天切换地点与路线
- 点击地点查看图片、介绍、地址与旅行提示
- 点击路线查看推荐交通方式、耗时与注意事项
- 新增和编辑地点，数据自动保存在浏览器本机
- JSON 行程导入与导出
- 第一次出国提醒与可勾选购买清单
- 手机底部导航与桌面双栏布局

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:5173`。

## 构建与部署

```bash
npm run build
```

项目使用静态导出，构建产物位于 `dist/client`，可以上传到任意静态服务器。若使用 GitHub Actions，把 `dist/client` 作为发布目录即可。

## 数据说明

地点编辑和购买清单使用浏览器 `localStorage` 保存，只在当前设备与浏览器中生效。导出 JSON 可用于换设备备份和恢复。
